FAQ

DNS lookup questions

What DNS records does this tool check?

The tool queries A, AAAA, MX, TXT, NS, and CNAME records. You can narrow record types in advanced options.

Can I check IP addresses?

Yes. The input accepts domains, IPv4 addresses, and IPv6 addresses. Reverse DNS can resolve IP addresses to hostnames.

How is the email security score calculated?

It evaluates SPF validity, DMARC policy strength, DKIM configuration, MX records, and related best-practice signals.

Is search history stored on your servers?

No. Search history is stored in browser localStorage and can be cleared from the history panel.
