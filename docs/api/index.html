DNS Intelligence API Discovery & Reference

This page documents the public DNS lookup contract advertised through the site's API catalog, OpenAPI description, and MCP discovery metadata.

Endpoint

Base URL https://api.lookup.echovalue.dev/dns-query
Method POST
Content Type application/json
OpenAPI /openapi/dns-query.json

Request Body

{
  "domains": ["example.com"],
  "recordTypes": ["A", "AAAA", "MX", "TXT", "NS", "CNAME"],
  "checkPropagation": false,
  "performReverseLookup": false,
  "enableEnrichment": true,
  "enableSslInspection": true,
  "timeout": 5000,
  "maxRetries": 3,
  "retryDelay": 1000,
  "includeMetadata": true
}

Authentication

The browser experience is protected by Turnstile. Programmatic access is currently exposed through hosted partners such as Apify and RapidAPI rather than a first-party OAuth issuer on this domain.
